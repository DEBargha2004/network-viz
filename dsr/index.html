Why DSR Over Pure Flooding?

Pure Flooding floods every single data packet to every node in the network, creating extreme bandwidth waste ("Broadcast Storm").

DSR (Dynamic Source Routing) Architecture:
  • 1. Reactive Discovery (RREQ): Flooding is only used once to find a path when no cached route exists. RREQ packets are lightweight.
  • 2. Route Accumulation: Each intermediate node appends its address to the RREQ header (e.g. [S, A, B]).
  • 3. Unicast Reply (RREP): Destination answers with RREP routed directly along the reverse path: [D, B, A, S].
  • 4. Source Routed Data: Once route is learned, DATA packets carry the full path in their header: [S → A → B → D]. No flooding is used for actual data!
  • 5. Route Caching: Nodes learn and cache routes snooped from packets passing by.

Comparison Summary

DSR Advantages
  • Zero flooding overhead for regular data packets
  • Loop-free routing by design
  • Nodes cache multiple alternative routes
DSR Overheads
  • Packet header size grows with path length
  • Route discovery latency on first packet
  • Route maintenance needed on link breaks
